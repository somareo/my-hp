Scope: DESIGN D — Design C's layout, type and hidden-thread gimmick, recoloured with Design A's palette (client request 2026-10-14). Persuade surface; action: LINE reservation. Mobile is the primary viewport.

## Direction contract
THESIS: The magazine you can unpick (Design C), worn in Design A's trust palette, so it is bold in structure and calm in colour. It refuses the beige-template default because the editorial structure stays intact.
OWN-WORLD: Ivory #F8F7F3 ground. Soft brown #51443D does the ink-field work (display type, owner/flow spreads, buttons). Warm beige #D5C6B8 is the "freedom" colour for the flood, reservation band and numerals. Pale beige #EFE8DF fields. Placeholder Unsplash photos are labelled 仮の写真. Same type as C: Archivo wide, Zen Old Mincho 900, Murecho.
STORY: Same as Design C, plus a photo spread after the concept so the salon feels real.
FIRST VIEWPORT: Same as Design C, with the treatment-room photo as the tilted insert. Its lower half is washed with ivory so the brown display type stays legible.
FORM: Inherits Design C (Marquee Hero → Split spreads). Signature interaction is THE HIDDEN THREAD, unchanged. seed: none (brief-pinned by client spec; no concept roll)
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
